# draftline

Pre-launch site for Draftline Studio: a cap, socks and a musette, each marked with one line.

Plain HTML, CSS and JavaScript. No build step.

## Before sharing the link

- **Waitlist:** the form does not collect emails yet. Set `WAITLIST_ENDPOINT` at the top of `main.js` to a form endpoint that accepts a JSON POST (for example a Formspree form URL).
- **Prices:** the prices shown are expected prices, not final.
- **Product images:** the products are drawings. Replace them with photos once samples arrive.

## Hosting

Served by GitHub Pages from the `main` branch. GitHub Pages does not allow sites that mainly exist to sell, so move hosting before adding checkout.
